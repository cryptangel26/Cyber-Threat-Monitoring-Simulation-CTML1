## 📋 Overview

This repository contains a complete incident response simulation based on a real-world SMB brute-force attack scenario. It includes:

- **Network Traffic Captures** (Wireshark PCAP files)
- **Windows Event Logs** (Event Viewer screenshots)
- **Tier 1/2/3 Incident Analysis** (Multi-level investigation)
- **Attack Timeline** (Phase-by-phase breakdown)
- **Mitigation Procedures** (Approved remediation actions)
- **Lessons Learned** (Post-incident observations)
- **Security Hardening Guides** (Technical implementation)

### 🎯 Learning Objectives

By working through this simulation, analysts will learn to:

✅ **Identify attack patterns** in network traffic using Wireshark  
✅ **Correlate events** between network captures and Windows logs  
✅ **Classify threats** using MITRE ATT&CK framework  
✅ **Assess risk** and determine appropriate responses  
✅ **Implement mitigations** for SMB-based attacks  
✅ **Document findings** in professional incident reports  
✅ **Brief leadership** on security incidents and decisions
